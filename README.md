## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的批量写入写到一半崩溃会留下半套数据，需要要么全部生效要么全部不生效。请从零实现一个原子批量写入组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持把一批键值写入作为一个原子单元提交，提交前对外不可见；2) 全成功或全失败：中途任何一步失败必须回滚本批已应用的修改，需有测试证明；3) 支持崩溃恢复：进程在提交过程中崩溃后重启，数据必须处于"全部生效"或"全部不生效"两种状态之一，不得出现半套；4) 支持重放幂等：崩溃恢复后重复提交同一批（按批次 ID 判断）不得重复生效；5) 支持读写并发：提交过程中其它线程的读取要么看到整批旧值要么整批新值，不得混合；6) 支持批次大小限制与拒绝对应的错误提示；7) 提供统计：批次数、提交成功数、回滚数、恢复时的重放次数与平均批大小；8) 测试覆盖原子提交、失败回滚、崩溃恢复两种状态、重放幂等、并发读写一致性与统计；`mvn -q verify` 一条命令跑通。

## 提交要求

3. 完成后在所属分支（A 或 B）上提交，产物快照的父提交必须是初始环境快照。
